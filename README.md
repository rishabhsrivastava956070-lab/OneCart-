# 🛒 OneCart – Full Stack E-commerce Website

OneCart is a complete **Full Stack E-commerce platform** where users can browse products, add items to cart, place orders, and make secure payments.

Built using **MERN Stack** with modern UI and real-world shopping workflow.

---

## 🚀 Features

### 👤 Authentication
- User signup & login
- Secure authentication with JWT / cookies
- Protected routes for users

### 🛍️ Products
- Browse all products
- View product details
- Category-wise filtering
- Product images and pricing

### 🛒 Cart System
- Add to cart
- Remove from cart
- Update quantity
- Real-time total price calculation

### 💳 Checkout & Orders
- Order placement flow
- Shipping details form
- Order summary before payment
- Payment integration (Razorpay / Stripe if used)

### 📦 Order Management
- User order history
- Order status tracking

### 🧑‍💼 Admin Features (if implemented)
- Add new products
- Update product details
- Delete products
- View all orders

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit (state management)
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- Razorpay / Stripe (for payments)
